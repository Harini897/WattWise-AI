
# WattWise AI

## Project Overview
WattWise AI is a confidence-based consumer-to-transformer mapping recovery system.

It aims to identify the distribution transformer connected to each electricity consumer using available electricity data and analytical methods.

## Project Goals
- Organize consumer and transformer data.
- Clean and validate electricity datasets.
- Prepare energy accounting data.
- Support consumer-to-transformer mapping recovery.
- Generate confidence scores for predicted mappings.

## Technology Stack
- Python for data processing
- SQLite for structured data storage
- HTML, CSS, and JavaScript for the frontend
- Git and GitHub for version control

## Project Structure
- `data/` — Electricity datasets
- `backend/` — Data processing code
- `models/` — Mapping and prediction logic
